# Privacy Policy

**Project:** Cercle de l'Économie Analytics Tool  
**Last Updated:** October 2026  

1. **Data Collection:** This tool accesses authorized account analytics via the TikTok API, including profile information, follower counts, and video view counts.
2. **Data Usage:** Data collected is used solely for creator dashboards and content planning. No personally identifiable user information is stored, processed, or shared with third parties.
3. **Data Retention:** Retained performance metrics can be deleted upon request or by revoking developer app access.
